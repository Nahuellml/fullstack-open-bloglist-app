# Blog List Application 🚀

This is my implementation of the Blog List backend from the Full Stack Open
bootcamp, Part 4.

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express
- **Database:** MongoDB (Mongoose)
- **Testing:** Node:test (Native) & Supertest

## 💡 A Personal Note on Part 4: The Testing Revelation

Before starting this module, I knew absolutely nothing about testing or
Test-Driven Development (TDD). To be honest, it has been a total eye-opener.
I had no idea that software could be developed this way, and it completely
changed my perspective on coding.

This is the reason I took my time to finish this part. I didn't want to just
"pass" it; I wanted to truly dive deep into how testing works, how to write
them effectively, and how to apply best practices. It was a real "click" in
my head.

I now realize that testing isn't just about finding bugs—it's about a whole
new way of thinking and building more reliable software. This has been, without
a doubt, a turning point in my journey as a developer.

## 🚀 Getting Started

1. Install dependencies: `npm install`
2. Run tests: `npm test`
3. Run development mode: `npm run dev`
